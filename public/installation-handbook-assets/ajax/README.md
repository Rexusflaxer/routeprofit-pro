# Ajax-installatiehandleidingen

Deze map bevat ongewijzigde officiële Ajax Systems-beelden en -pictogrammen die LOQ gebruikt om operationele handboekartikelen herkenbaar te maken.

- Elke inhoudelijke release krijgt een eigen map en manifest; bestaande releases worden niet overschreven.
- Records verwijzen uitsluitend naar een gecontroleerde `asset_key`, nooit naar een willekeurige externe URL.
- De Nederlandse instructietekst is door LOQ geschreven. De fabrikantshandleiding wordt niet gekopieerd.
- Ajax Systems behoudt alle rechten op de beelden. Leg vóór productiegebruik de toepasselijke Ajax-partner- of merktoestemming vast.
- Bronpagina, bron-URL, ophaaldatum, checksum en alternatieve tekst staan in het release-manifest.
